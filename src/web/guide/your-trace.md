# Open a local trace

- For a quick look, use [File → Open trace…](#do:btn-open) (Ctrl/⌘ O) and choose a trace.
- For large traces, saved analysis, or AI access, install `heapviz` from [File → Setup…](#do:btn-setup).
- Run `heapviz open TRACE_FILE`.
- Copy the complete **Browser connection**, including everything after `#`.
- Paste it into [File → Connect…](#do:btn-connect) (or click the connection pill) and keep the terminal open.

No trace yet? Setup includes a command that downloads and opens the full demo through `heapviz`.
