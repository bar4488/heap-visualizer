# Open a local trace

- For a quick look, click [Open…](#do:btn-open) and choose a trace.
- For saved analysis or AI access, open [Setup](#do:btn-setup) and install `heapviz`.
- Run `heapviz open TRACE_FILE`.
- Copy the complete **Browser connection**, including everything after `#`.
- Paste it into **Connect this browser** and keep the terminal open.

No trace yet? Setup includes a command that downloads and opens the full demo through `heapviz`.
