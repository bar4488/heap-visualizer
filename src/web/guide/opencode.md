# Connect an AI assistant

- Install the skill for your assistant:

```
heapviz setup opencode
heapviz setup claude
```

- Start a trace with `heapviz open TRACE_FILE`.
- Copy the complete **AI assistant** instruction into OpenCode or Claude.
- Include everything after `#`; the URL alone cannot connect.
- Ask the assistant what you want to learn.

The assistant and browser share the same names, tags, filters, and marks.
